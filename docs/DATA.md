# External research assets

Full inversion requires the complete synthetic HDF5 dataset and the trained conditional-network checkpoint. They are intentionally excluded from Git tracking. The source-data tables and diagnostic arrays included here do not replace the complete training/evaluation dataset.

Record the final public repository identifiers, checksums and access instructions for these two assets in this file when released. No public asset URL is claimed by this package.

External asset checksums are recorded in `assets_manifest.json` in this directory.
